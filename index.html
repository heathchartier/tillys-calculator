Optimizer Settings

Raw stock ships 1" oversize vs. nominal (e.g. a "4x8" is a true 49"x97" panel) — 0.5" per edge squaring trim below exactly consumes that oversize back down to nominal, matching Tilly's own sheet-count history. Kerf defaults to 0 for the same reason: several finished sizes divide the raw stock with zero margin, so this shop's planning doesn't reserve kerf loss. Raise it only if you want to build in real blade-width margin.
